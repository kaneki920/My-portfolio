## Built With

- HTML5
- CSS3
- Google Fonts: DM Mono and Manrope
- GitHub Pages for static hosting

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in your browser. For a more realistic local server, use the Live Server extension in Visual Studio Code.

No build step, package manager, or JavaScript framework is required for this static site.
