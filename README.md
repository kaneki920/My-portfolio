# Avnish — Personal Portfolio

A personal developer portfolio built with **HTML5 and CSS3**. It presents my learning journey, current skills, projects, and ways to connect.

> **Code files are intentionally left empty in this starter package.** Paste your existing HTML into `index.html` and your existing CSS into `style.css`. No changes have been made to your supplied code.

## Run Locally

1. Download or clone this repository.
2. Paste your existing HTML into `index.html` and CSS into `style.css`.
3. Keep the stylesheet reference in your HTML aligned with the filename: `style.css`.
4. Open `index.html` in your browser. For a more realistic local server, use the Live Server extension in Visual Studio Code.

No build step, package manager, or JavaScript framework is required for this static site.

## Publish with GitHub Pages

1. Create a GitHub repository named `avnish-portfolio` (or any name you prefer).
2. Upload the contents of this folder to the repository root. Make sure `index.html` and `style.css` are at the root level.
3. On GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and the `/(root)` folder, then save.
6. Wait for the deployment to finish. GitHub will display your published site URL in the Pages section.

If you want the portfolio at `https://<your-username>.github.io/`, name the repository exactly `<your-username>.github.io`.
